# 🏆 Kim Milyoner Olmak İster?

Python və Tkinter ilə hazırlanmış, məşhur "Kim Milyoner Olmaq İstər?" televiziya proqramından ilhamlanan masaüstü bilik yarışı oyunu.

## 🎮 Xüsusiyyətlər

- 20 sualdan ibarət, çətinlik səviyyəsi artan sual bankı
- 3 klassik joker: **50:50**, **Seyirci köməyi**, **Telefon köməyi**
- Real vaxtda pul/mükafat sayğacı (para_listesi əsasında)
- Baraj sistemi (5-ci və 10-cu suallardan sonra təhlükəsiz məbləğ)
- Səs effektləri (doğru/yanlış cavab üçün)
- Tkinter ilə dizayn edilmiş qrafik interfeys (GUI)

## 🛠️ İstifadə olunan texnologiyalar

- Python 3
- Tkinter (GUI)
- winsound (səs effektləri — yalnız Windows üçün işləyir)
- random modulu

## 🚀 Necə işə salmaq olar

```bash
python milyoner.py
```

**Qeyd:** `winsound` modulu yalnız Windows əməliyyat sistemində mövcuddur, ona görə oyun hazırda yalnız Windows-da işləyir.
